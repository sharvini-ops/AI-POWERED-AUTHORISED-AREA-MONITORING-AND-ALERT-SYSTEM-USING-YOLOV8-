AI-Empowered Authorized Area and Alert System (YOLOv8)

📌 Overview

The AI-Empowered Authorized Area and Alert System is a computer vision–based security solution that monitors restricted or authorized areas in real time. Using YOLOv8 for object detection, the system identifies humans (or other specified objects) entering predefined zones and triggers alerts when unauthorized access is detected.

This project is designed for applications such as:

* Smart surveillance systems
* Restricted area monitoring (labs, data centers, factories)
* Campus or industrial security
* Automated intrusion detection

🚀 Features

🔍 Real-time object detection using YOLOv8
🧠 Authorized vs unauthorized area monitoring
📐 Customizable detection zones (ROI)
🚨 Instant alerts (sound, visual, or notification-based)
📹 Live video stream processing (CCTV / webcam / video file)
📝 Event logging for security analysis

🛠️ Technologies Used

* Python 3.x
* YOLOv8 (Ultralytics)
* OpenCV
* NumPy

CVZone / Shapely (optional for region detection)

SMTP / Twilio / Local Alarm (for alerts, optional)
